What it does

Built for messy contact exports

PSClean handles the tedious, error-prone parts of contact cleanup so you can focus on the judgment calls that actually need a person.

Smart duplicate detection

Identifies matching contacts across your export and clusters related records into duplicate groups.

Auto-merge with confidence

High-confidence duplicates are merged automatically, while uncertain pairs are flagged for your review.

Review queue

Work through flagged pairs one at a time — merge, skip, reject, or edit the merged result before export.

Manual edit dialog

Adjust phone types, drop duplicate entries, or add missing emails and addresses before a record goes back in.

Guardian reference lookup

Open a side-by-side Guardian Info window (great on a second monitor) to verify details while you review.

Direct PowerSchool API

Pull contacts straight from PowerSchool over OAuth2, or work from a CSV export — your choice.

How it works

Three steps, start to import

From a raw export to a clean, import-ready file — with a human checkpoint in the middle.

1

Process

Load your PowerSchool contacts, weight automatically via the API or via a csv export, pick an output folder, and run deduplication. PSClean merges the obvious duplicates and queues the rest.

2

Review

Each row is a flagged pair. Merge it, approve a whole duplicate cluster at once, skip, reject, or open the editor to fine-tune the merged contact.

3

Export & import

Press one button to commit to Powerschool, or write the result files and load import_ready.csv through System → Page & Data Management → Import & Export Data → Contacts.

What you get

Five files on every export

Rows with a populated ID update existing records; rows with only an Identifier create new ones.

Credentials & security

Your secrets stay on your machine

When connecting to the PowerSchool API, PSClean never writes your client secret to disk in plaintext.

  • Encrypted with Windows DPAPI

    If you choose "Remember on this PC", credentials are encrypted with the Windows Data Protection API and saved to %APPDATA%\PSClean.

  • Tied to your account

    DPAPI binds the ciphertext to your Windows user on that machine — only the same user on the same PC can decrypt it.

  • Enter once, forget anytime

    Later launches reload automatically. Use "Forget saved" or "Disconnect" to clear stored or in-memory credentials.
